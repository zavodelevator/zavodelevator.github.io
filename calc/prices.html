⚙ Ціни калькуляторів Завантаження…
Як це працює
  1. Усі ціни калькуляторів лежать в одному файлі calc/prices/prices_РРРР-ММ-ДД_ГГ-ХХ.json. Кожен калькулятор бере файл з найпізнішою датою, не пізніше сьогодні.
  2. Змініть ціни нижче (змінені поля підсвічуються жовтим) і натисніть «Завантажити JSON» — файл збережеться з поточною датою й часом у назві.
  3. Покладіть файл на GitHub у папку calc/prices (Add file → Upload files → Commit). Старі файли не видаляйте — це історія цін.
  4. Однакові ціни (той самий товар у кількох калькуляторах) показано один раз; під ціною видно, де вона використовується.
  5. ✎ жовті — ціни, які заповнив Claude (з ваших таблиць, з інтернету або оцінка). Неточні: перевірте й виправте або натисніть «✓ підтвердити». Синім — змінені вами.
  6. Ціни норії з каталогу НКЗ (головки, башмаки, шахти, ковші, стрічки, ланцюги) змінюються в Google-таблиці НКЗ, не тут.
